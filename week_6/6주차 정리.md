
## 5. 미분의 연쇄 법칙과 신경망 학습 안정화
- 다층 퍼셉트론은 어떻게 가중치를 스스로 고칠까?
- ### 학습은 가중치를 조정하는 과정
	- 입력 x -> 예측 y^ -> 정답 y와 비교 -> 가중치 수정
	- 같은 입력에도 가중치가 바뀌면 예측값이 달라진다
		- 목표 : 처음 보지 않은 데이터에서도 예측 오차를 줄이기
- ### 손실 함수는 예측 오류를 숫자로 표현
	- 회귀와 분류에는 서로 다른 손실을 쓴다
	- 모델이 얼마나 틀렸는가?
		- MSE = (1/n)(sigma)(y1 - y1^)^2
		- MSE : 실제값과 예측값의 차이를 제곱하여 평균
		- 교차 엔트로피 : 정답 범주에 준 확률이 낮을수록 큰 벌점
- ### 미분은 작은 변화에 대한 반응
	- 입력값을 조금 바꾸어 본다
	- 기울기 = 출력 변화 / 입력 변화
	- 양수 기울기 : x를 올리면 함수값 증가
	- 음수 기울기 : x를 올리면 함수값 감소
- ### 경사하강법으로 가중치 수정
	- 기울기 반대 방향으로 한 걸음
	- 현재 손실에서 낮아지는 방향 찾기
	- n는 학습률이다.
	- 너무 크면 최솟값을 지나칠 수 있고, 너무 작으면 학습이 느리다
- ### 첫 층의 가중치가 손실에 미치는 영향
	- 첫 가중치 w -> 은닉층 h -> 예측 y^ -> 손실 L
	- 질문 : w를 아주 조금 바꾸며 최종 손실 L은 얼마나 변할까?
- ### 합성함수와 연쇄 법칙
	- 출력이 다시 다음 함수의 입력이 된다
	- x -> u = g(x) -> L = f(u)
	- 전체 변화율은 경로를 따라 단계별 변화율을 곱함
	- 예 : x가 u에 미치는 영향 x u가 L에 미치는 영향
- ### 순전파와 역전파
	- 입력 x -> 은닉값 h -> 예측 y^ -> 손실 L
	- 순전파 : 왼쪽에서 오른쪽으로 값을 계산
	- 역전파 : 오른쪽에서 왼쪽으로 손실의 기울기를 계산
