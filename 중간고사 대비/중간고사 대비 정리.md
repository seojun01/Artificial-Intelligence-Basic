## Part 1. 반드시 알아야 할 핵심 내용

### 2주차 — 인공지능은 무엇을 학습하는가
- **규칙 기반 vs 학습 기반**: 사람이 규칙 작성(명확하지만 예외 처리 한계) vs 데이터에서 X→y 관계를 스스로 찾음
- **문제 구조화**: 현실 문제 → 데이터 → 학습 문제 (X → y)
- **좋은 학습 문제의 3가지 기둥**: **관측 대상**(무엇이 한 행인가) · **시점**(언제까지의 정보로 언제를 예측) · **출력**(숫자/범주/집단)
- **구성 요소**: X(입력 특징) / y(실제 정답, Ground Truth) / ŷ(예측값) / f(모델) / 관측 대상 = 한 행(Row, Instance)
- 텍스트·이미지·오디오 모두 결국 **숫자 행렬 X**로 변환
- **학습 유형**

| 유형 | 제공 정보 | 목표 | 예 |
|---|---|---|---|
| 지도학습 – **회귀** | X, y(연속 수치) | 수치 예측 | 집값, 기온 |
| 지도학습 – **분류** | X, y(범주) | 범주 예측 | 스팸, 질병 유무 |
| 비지도학습 | X만 | 숨은 구조 발견 | 군집화, 차원 축소, 이상치 탐지 |
| 강화학습 | 상태·행동·보상 | **누적 보상 최대화** | 게임 AI, 자율주행 |

- **데이터 누출(Data Leakage)**: 예측 시점에는 알 수 없는 **미래 정보**가 X에 포함 → 성능 착시 (예: 스팸 판별에 '사후 신고', '차단버튼클릭' 포함 → 100% vs 실제 85.7%)
  - 판별 질문: **시점**(그 순간 알 수 있나) · **인과**(정답 이후 생긴 결과 아닌가) · **재현**(새 데이터에도 같은 방식으로 구할 수 있나) — 하나라도 '아니오'면 삭제
- **좋은 특징 4가지 점검**: 관련성, **가용성(누출 방지)**, 측정 가능성, 적절성(개인정보·편향·윤리)
- **윤리**: 개인정보(최소 수집, 동의, 재식별 위험, 마스킹), 편향·공정성(대표성, 집단별 오류 차, 정답 자체의 편견)
- **클래스 불균형** 함정: 99%가 정상이면 '전부 정상'만 찍어도 정확도 99%

### 3주차 — 모델의 학습과 성능 평가
- 목표 = 훈련 데이터 암기가 아니라 **안 본 데이터에서의 예측(일반화)**
- **매개변수(Parameter)**: 모델이 학습으로 스스로 조정 (W, b, `model.coef_`) / **하이퍼파라미터**: 학습 전에 사람이 정함 (학습률, max_depth, degree, K)
- **손실함수**: 회귀 → **MSE**(제곱: 부호 상쇄 방지 + 큰 오차에 큰 벌점) / 분류 → **교차 엔트로피**(정답을 낮은 확률로 예측할수록 큰 벌점)
- **경사하강법**: 기울기의 반대 방향으로 이동 **w ← w − η·∂L/∂w**
- **학습률 η**: 너무 작으면 느린 수렴, 너무 크면 발산/진동
- **데이터 분할**: Train(70%, 매개변수 학습) / Validation(15%, 하이퍼파라미터 조정) / **Test(15%, 마지막 한 번만)** — 테스트를 보고 설정을 바꾸면 간접 학습
- **과소적합 vs 과적합**

| 상태 | Train 성능 | Test 성능 | 다항회귀 예 |
|---|---|---|---|
| 과소적합 | 낮음(MSE 큼) | 낮음 | degree 1 |
| 적절 | 높음 | 높음 | degree 3~4 |
| **과적합** | **매우 높음** | **상대적으로 낮음** | degree 15 |

- 과적합 = 잡음까지 규칙으로 외움. Train과 Test 성능 **격차**가 신호
- **회귀 지표**: MAE(절댓값 평균, 원래 단위) / MSE(큰 오차에 민감) / RMSE(√MSE, 원래 단위) / **R²**(평균만 찍는 것보다 얼마나 나은가, 1에 가까울수록 좋음)
- **혼동행렬**: TP, FP(오탐), FN(놓침), TN
  - 정확도 = (TP+TN)/전체 / **정밀도 = TP/(TP+FP)** / **재현율 = TP/(TP+FN)** / **F1 = 2PR/(P+R)**
  - **정밀도 중요**: 스팸 필터(정상 메일 차단 FP 방지) / **재현율 중요**: 암 진단(환자를 놓치는 FN 방지)

### 4주차 — 비지도학습: K-means, PCA
- 지도학습은 예측–정답 오차를 줄이고, 비지도학습은 **데이터 내부 구조(거리·분산)** 를 최적화
- **K-means**: 사전 결정 = **K, 거리 기준, 초기 중심**
  - 반복: ① 배정(가까운 중심) → ② 갱신(중심 = 군집 평균) → ③ 변화 확인 → ④ 중심이 안 움직이면 종료
  - 손실 = 데이터와 군집 중심 사이 거리(제곱합, **inertia**). **K가 커질수록 inertia는 무조건 감소** → 최솟값으로 K 선택 X, 도메인 지식 필요
  - 군집 번호(0, 1, 2)는 품종 이름이 아니라 단순 ID / **군집 ≠ 분류**
- **차원의 저주**: 특징이 많을수록 공간이 방대해져 데이터가 고립, 거리 개념 붕괴, 잡음 특징 → 과적합
- **PCA(주성분 분석)**: 정보(**분산**)를 가장 많이 담는 새 축으로 투영
  - 공분산 행렬의 **고유벡터 = 새 축 방향**, **고유값 = 그 축이 설명하는 분산 크기** → 가장 큰 고유값의 고유벡터가 PC1
  - 4단계: 중심화·표준화 → 공분산 계산 → 축 선택(고유값 큰 순) → 투영
  - `explained_variance_ratio_`: 각 주성분의 설명 분산 비율 (예: PC1 68% + PC2 22% = 90% 보존)
- **함정**: ① **단위 차이** — 거리 기반 방법은 큰 단위 특징에 지배됨 → **StandardScaler**(평균 0, 표준편차 1) ② **누출** — 스케일러·PCA는 **Train으로만 fit**, Test에는 transform만
- Iris 실습: 꽃받침·꽃잎 길이·너비 4개 특징, `KMeans(n_clusters=3)`, `PCA(n_components=2)`

### 5주차 — 퍼셉트론에서 MLP까지
- **인공 뉴런**: 입력 x × 가중치 w(중요도) → 가중합 z = Σwx + b(편향: 기준선 이동) → 활성화 함수
- **단층 퍼셉트론**: z ≥ 0이면 1, 아니면 0 (계단 함수) → **직선 하나**의 결정 경계
  - AND, OR은 선형 분리 가능 / **XOR은 불가능** → 첫 번째 **AI 겨울**
- **은닉층**: 원본 데이터를 풀기 쉬운 **새로운 표현**으로 변환 (위원회 비유)
- **선형성의 덫**: 활성화 없이 층만 쌓으면 (XW₁)W₂ = X(W₁W₂) → 결국 선형 하나 → **비선형 활성화 함수 필수**
- **활성화 함수**

| 함수 | 특징 | 평가 |
|---|---|---|
| 계단(Step) | 0/1, 미분 불가 → 학습 불가 | 퇴출 |
| 시그모이드 | 0~1 확률, 미분 최대 **0.25** → 기울기 소실 | 출력층 등 제한적 |
| **ReLU** | max(0, z), 계산 빠름, 양수 기울기 1 | 현대 표준(은닉층) |

- **MLP** = 입력층 + 은닉층(가중합 + 활성화 반복) + 출력층
- **순전파**: Z₁ = XW₁ + b₁ → A₁ = ReLU(Z₁) → Z₂ = A₁W₂ + b₂ → ŷ = sigmoid(Z₂)
- **행렬 shape 규칙**: (N × **M**) @ (**M** × K) = (N × K) — 안쪽 차원 일치 필수. 샘플 수(행)는 유지, 열 = 그 층의 뉴런 수
- 행렬 연산 → GPU 병렬 처리가 AI의 핵심인 이유

### 6주차 — 역전파 (가중치를 스스로 고치기)
- 학습 4단계: **예측(순전파) → 손실 계산 → 기울기 계산(역전파) → 가중치 수정**
- 미분 = 작은 변화에 대한 반응, 기울기 양수면 w↑ → L↑
- **연쇄 법칙**: x → u → L 일 때 **dL/dx = (dL/du)(du/dx)**
  - 예: u = 3x, L = u², x = 2 → dL/du = 2u = 12, du/dx = 3 → **36**
- **순전파는 왼→오(값 계산), 역전파는 오→왼(기울기 계산)**
- 한 뉴런: z = wx + b → h = σ(z) → ŷ = vh → L
  - **∂L/∂w = (∂L/∂ŷ)(∂ŷ/∂h)(∂h/∂z)(∂z/∂w) = (ŷ − y) · v · h(1−h) · x**
- 실습 수치: x=1, y=1, w=0.5, b=0, v=1 → z=0.5, h=0.6225, L=½(ŷ−y)²=0.0713, grad = −0.3775 × 1 × 0.2350 × 1 = **−0.0887**, lr=0.5 → w_new = **0.5444**
  - 기울기가 음수면 w는 **커진다**
- **수치 미분 검산**: (L(w+ε) − L(w−ε)) / 2ε (중앙 차분)
- 시그모이드 + 교차 엔트로피를 함께 미분하면 출력 오차 = **(P − Y)/n**
- 학습 전 이진 교차 엔트로피 ≈ **ln 2 = 0.693** (모두 0.5로 찍는 상태) / 10클래스면 **ln 10 ≈ 2.30**
- 학습률 비교(XOR): 0.01 → 손실 0.694(거의 안 배움), 1.0 → 0.0019(성공), 200 → 진동·발산

### 7주차 — 깊은 신경망 학습 안정화
- **Part 1 기울기 소실**: 시그모이드 미분 최대 0.25 → 10층이면 0.25¹⁰ ≈ **100만 분의 1** → 앞쪽 층이 학습 못 함
  - 해결: **ReLU**(양수 기울기 1, 단 **죽은 ReLU** → Leaky ReLU) + **가중치 초기화**
  - **Xavier**: Var(w) = 2/(n_in + n_out) → 시그모이드·tanh / **He**: Var(w) = 2/n_in → ReLU
  - 실습: 1층/10층 기울기 비율 — 시그모이드 1.6×10⁻⁸ vs ReLU+He 0.78 / 정확도 10.2% vs 95.9%
- **Part 2 최적화**
  - **SGD**: 미니배치로 경사 추정 → 흔들림 (얕은 골 탈출엔 도움). 좁고 긴 골짜기에서 지그재그, 평지·안장점에서 느림
  - **모멘텀**: v ← βv + g (β=0.9) — 같은 방향이면 가속, 번갈아 바뀌면 상쇄
  - **Adagrad**: 기울기 제곱을 계속 누적 → 보폭이 0에 가까워져 학습이 멈출 수 있음
  - **RMSprop**: 기울기 제곱의 **이동평균**(ρ≈0.9) → 보폭 유지
  - **Adam = 모멘텀(방향) + RMSprop(보폭)**, 기본값 η=0.001, β₁=0.9, β₂=0.999, 초반 편향 보정
- **Part 3 규제화(과적합 방지)**: 훈련 손실↓ 검증 손실↑ = 과적합
  - **L1** λΣ|w| → 덜 중요한 가중치를 **정확히 0**(특징 선택) / **L2** λΣw² → 모두 고르게 작게(weight decay)
  - **드롭아웃**: 훈련 때만 무작위 뉴런 끄기(p=0.5), 테스트 땐 모두 켬 → 앙상블 효과
  - **조기 종료**: 검증 손실이 **patience**번 연속 개선 없으면 멈추고 **최고였던 가중치 복원**
- **증상 → 처방 표**

| 증상 | 원인 | 처방 |
|---|---|---|
| 앞층 기울기 ≈ 0, loss 안 줄어듦 | 기울기 소실 | ReLU + He 초기화 |
| loss 갑자기 커지거나 NaN | 기울기 폭발 | 학습률↓, 초기화 점검 |
| loss 들쭉날쭉, 느림 | 보폭·방향 문제 | 모멘텀·Adam, 학습률 조정 |
| 훈련↓ 검증↑ | 과적합 | L2, 드롭아웃, 조기 종료 |
