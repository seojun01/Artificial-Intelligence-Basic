
## 정답 없이 데이터 스스로 말하게 하는 법
### 비지도 학습
- 지도학습 : 예측과 정답의 차이
	- 정답과의 오차를 줄이는 훈련
- 비지도학습 : 데이터 내부의 구조 탐색
	- 데이터 내부의 거리와 분산을 최적화하는 탐험
- #### 캄캄한 공간에서 우리가 찾아낼 수 있는 네가지 구조
	- 구객 세분화 : 구매 패턴이 비슷한 고객군 묶기
	- 문서 탐색 : 내용이 비슷한 문서들의 군집화
	- 이상 탐지 : 정상 패턴에서 멀리 떨어진 사례 찾기
	- 시각화 : 수백 개의 특징을 2차원 지도로 요약하기
### K-means
- 거리 + 반복 = 군집 내부의 최적화
	- 각 점을 가까운 중심에 배정하고, 중심을 다시 계산함
- #### 세 가지 규칙
	- K (군집의 개수) : 운동장에 몇 개의 깃발을 꽂을 것인가?
	- 거리 (가까움의 기준) : 어떤 길을 따라 걸을 것인가?
	- 초기 중심 (출발점) : 첫 깃발을 어디에 던질 것인가?
- #### 운동장 깃발 비유 : 군집이 완성되는 4단계 라이프사이클
	1. 배정(가까운 깃발로)
	2. 갱신(중심을 찾기)
	3. 확인(아직 움직이는가)
	4. 종료(스위치 딸깍)
- #### 비지도 학습도 결국 손실을 줄이는 과정임
	- 지도학습의 손실
		- 예측값과 정답 사이의 오차
	- 비지도학습의 손실
		- 데이터와 군집 중심 사이의 '거리(텐션)'
		- K-means는 이 고무줄들의 전체 장력이 최소화되는 가장 편안한 상태를 찾는 최적화 과정임
- #### K가 달라지면, 데이터가 들려주는 이야기도 달라짐
	- 손실은 K가 커질수록 무조건 줄어듦
	- 하지만 '수학적 최적'이 항상 '현실의 정답'은 아님
	- 도메인 지식을 통한 해석이 필수적임
### 차원의 저주
- 골목길에서 우주로 : 차원이 늘면 이웃이 사라짐
	- 1차원 (골목길)
		- 필요 격자 : 10^1
		- 닿을 듯 가까운 이웃
	- 2차원 (광장)
		- 필요 격자 : 10^2
		- 100명이면 다시 구조가 보임
	- 고차원 (우주)
		- 필요 격자 : 10^100
		- 공간이 너무 방대하여 모두가 홀로 고립됨
- 잡음 특징은 모델을 '융통성 없는 암기생'으로 만듦
	- 거리 개념의 붕괴
		- 최근접 거리와 최원 거리의 차이가 희미해져 '누가 더 가까운가' 판단 불가
	- 잡음에 집중하는 과정합(Overfitting)
		- 새로운 문제(Test data)에서 흔들리는 모델 vs 원리를 파악한 일반화 모델
### 주성분 분석(PCA)
- PCA는 불필요한 차원을 버리고, 데이터의 정보(분산)를 가장 많이 담아내는 '새로운 축'을 찾는 과정임
- #### 그림자 비유
	- 일반 변수 축 (나쁜 각도)
		- 특징이 뭉개진 둥근 그림자(낮은 분산)
		- 새인지 공인지 알 수 없음
	- 제1주성분 축 (최적의 각도)
		- 형태가 완벽하게 보존된 넓은 그림자(가장 큰 분산)
	- 데이터가 가장 넓게 퍼지는 방향(=분산이 최대화되는 축)이 곧 정보 손실이 가장 적은 최적의 투영 좌표임
- #### 빛과 그림자의 선형대수학
	- 공분산 행렬 : 3D 허공에 떠 있는 데이터 구름 자체의 입체적인 모양
	- 고유값 : 그림자가 쫙 퍼진 넓이 (그 축이 설명하는 분산의 크기)
	- 고유벡터 : 빛을 비추는 '최적의 각도' (새로운 축의 방향)
	- 가장 큰 고유값를  가지는 v(고유벡터)가 바로 제 1주성분(PC1)이 됨
- #### PCA를 적용하는 4단계 파이프라인
	1. 중심화 및 표준화
		- 데이터를 원점(0,0)으로 옮기고 찌그러진 스케일 맞추기
	2. 공분산 계산
		- 특징들이 어떻게 함께 변하는지 입체적 구조 파악
	3. 축 선택
		- 빛을 비출 최고의 각도(고유벡터)를 고유값이 큰 순서대로 정렬
	4. 투영(Transform)
		- 원래의 데이터를 선택한 2D 캔버스(새 좌표)를 눌러 찍기
- #### 분산이 큰 축이 더 많은 데이터를 설명함
	- PC1 + PC2 = 단 2개의 새로운 축만으로도 전체 정보(분산)의 90% 보존 완료
### 현실 세계의 함정 : 단위와 누출
- 알고리즘은 훌륭하지만, 들어가는 데이터가 왜곡되면 결과도 왜곡됨
- #### 함정 1. 단위에 지배당한 알고리즘
	- 단위 왜곡 : kg vs mm
		- 꼬리 길이는 무시되고 숫자가 큰 몸무게 단위에 알고리즘이 지배당함
	- 공정한 기준 (Standardization)
		- 모든 특징이 동등한 잣대 위에서 공정한 거리 게산 가능
- #### 함정 2. 미래를 훔쳐보는 죄(데이터 누출)
	- 실패하는 모델 : 훈련과 테스트를 동시에 섞어 기준(fit)을 잡는 행위
	- 성공하는 모델 : 훈련 데이터로만 기준(fit)을 잡고, 테스트에 적용(transform)만 함
### 종합 : 비지도 학습도 '학습의 기본 원리' 안에 있습니다![[스크린샷 2026-10-17 at 15.08.37 1.png]]
- 정답이 없다는 것뿐, 비지도 학습 역시 목적함수와 최적화라는 AI의 거대한 법칙 안에서 완벽하게 작동함
- #### 본질을 남기고 복잡성을 줄이는 여정
	- K-means : 거리 손실을 줄이며 정답 없이 그룹을 찾는다
	- 차원의 저주 : 특징이 많아질수록 텅 빈 공간에 고립됨을 경계하라
	- PCA : 그림자(분산)가 가장 뚜렷한 축으로 투영하여 핵심을 남긴

## 실습
- ### 정답을 숨기고 데이터의 구조 찾아보기
	- #### 실습 데이터 : Iris
		- 4개의 측정값만 사용하고 실제 품종은 마지막에 확인한다
		- X : 꽃받침 길이, 너비, 꽃잎 길이, 너비
		- y : 실제 품종 - 처음에는 사용하지 않음
		- 목표 : X만 보고 데이터가 어떻게 묶이는지 확인
	- #### K-means로 데이터 묶기
		- 가까운 데이터끼리 묶고 군집 중심을 반복해서 갱신한다
		- `kmeans = KMeans(n_clusters=3, random_state=0, n_init='auto')`
		- `cluster = kmeans.fit_predict(X)`
		- 중심 배정 -> 중심 갱신 -> 반복
		- 정답 y는 사용하지 않음
		- K는 알고리즘이 자동으로 정해주는 정답이 아니다
			- n_clusters=3 : 군집의 수 K를 우리가 지정
			- fit_predict(X) : 군집을 학습하고 각 데이터의 군집 번호 반환
			- 군집 번호 0, 1, 2는 '품종 이름'이 아니라 단순한 군집 ID
	- #### 왜 표준화가 필요한가
		- K-means는 거리를 사용하므로 특성의 단위와 크기에 영향을 받음
		- StandardScaler : 각 특성을 평균 0, 표준편차 1 수준으로 맞춤
		- 표준화 전,후 군집 결과를 비교
		- 핵심 : 거리 기반 방법에서는 스케일이 결과에 영향을 줄 수 있음
	- #### K 바꿔보기
		- K = 2,3,4,5를 차례로 실행
		- 각 K에서 inertia를 기록
		- inertia는 K가 커질수록 감소하므로 '가장 작은 값'만으로 K를 고르면 안됨
	- #### 4차원을 어떻게 눈으로 볼까?
		- PCA로 정보가 많이 남는 새로운 축을 찾는다
		- `pca = PCA(n_components = 2)`
		- `X_pca = pca.fit_transform(X_scaled)`
		- 4개의 원래 특성 -> PC1, PC2 두 축
		- 시각화가 가능해지고 주요 변동을 압축해서 볼 수 있다
	- #### PCA 결과에서 볼 것
		- explained_variance_ratios_ 확인
		- PC1 + PC2의 누적 설명분산비 계산
		- 4개의 특성을 2개의 새로운 축으로 줄였을 때 정보가 얼마나 남았는지 해석
	- #### 군집 결과를 2차원에서 확인
		- PC1 x PC2 산점도
		- 색 = K-means가 만든 cluster
		- 이제 '정답 없이 발견한 구조'를 눈으로 확인할 수 있다
	- #### 마지막에 정답 공개
		- 왼쪽 : K-means가 발견한 군집
		- 오른쪽 : 실제 Iris 품종
		- 비슷한 부분과 다른 부분을 비교 -> 군집은 분류와 같지 않다
	- #### 오늘 실습의 연결
		- 비지도학습도 결국 '학습의 기본 원리' 안에서 작동한다
		- K-means : 거리 손실을 줄이는 방향으로 군집을 최적화
		- PCA : 분산을 많이 보존하는 축을 찾음
	- #### 실습 과제
		- 수업에서는 Iris 데이터를 k=3을 사용하였는데, k=2, k=4로 각각 바꾸어 군집화를 수행
		- PCA 공간에서 k=2와 k=4의 군집 결과를 그림으로 표현
		- 각 군집 결과를 실제 Iris 품종과 교차표로 비교
		- 다음 질문에 답하기
			- K=2와 K=4중 실제 Iris 품종의 구조와 더 비슷해 보이느 것은 어느 쪽인가?
			- 그 근거를 군집 그림과 교차표를 이용하여 설명하여라
