
## 퍼셉트론에서 다층 퍼셉트론(MLP)까지
- 목표 : 학습이 아닌, 인공지능이 어떻게 예측값을 도출하는지 그 '구조와 흐름'을 완벽히 이해
- ### 자연의 설계도 vs 공학자의 설계도
	- #### 자연의 설계도
		- 신호 수신(Dendrite)
		- 시냅스 연결(Synapse)
		- 세포체(Soma)
		- 축산둔덕(Axon Hillock)
	- #### 공학자의 설계도
		- 입력 데이터(Input, x) : 외부 환경의 정보
		- 가중치(Weight, w) : '볼륨 조절기' - 각 정보의 중요도를 결정
		- 가중합(Summation) : 들어온 신호들의 총합을 계산
		- 활성화 함수(Activation, f) : 신호를 다음으로 보낼지 결정![[스크린샷 2026-10-17 at 15.34.17.png]]
- ### 가장 단순한 뇌 : 단층 퍼셉트론
	- #### 오늘 우산을 챙길 것인가?
		- x1 : 일기예보 비 확률(0.8) -> w1 : 비 예보의 중요도
		- x2 : 현재 구름의 양(0.5) -> w2 : 구름 양의 중요도
		- b : 편향(기본적인 성향 - 우산 챙기기를 귀찮아하는 정도)
			- -> 가중합 및 활성화
				- y = f(w1\*x1 + w2\*x2 + b)
		- 결론 : 우산을챙긴다(1) or 안 챙긴다(0)
		- 입력값에 중요도(가중치) 곱하고 기본 성향ㅇ(편향)을 더해, 하나의 결론을 도출하는 가장 단순한 형태의 지능
- ### 수학적 장벽과 AI 겨울 : XOR 문제
	- 단층 퍼셉트론의 치명적 한계
		- 하나의 선으로는 절대 풀 수 없는 문제의 등장
		- 이 수학적 장벽이 첫 번째 'AI 겨울'을 불렀음
	- #### 돌파구 1 : 은닉층(Hidden Layers)의 등장
		- 단일 결정에서 위원회 합의로
		- 핵심 : 은닉층은 원본 데이터를 해결하기 쉬운 '새로운 표현'으로 변환하는 역할을 함
	- #### 선형성의 덫(The Trap of Linearity)
		- 경고 : 비선형성의 부재
			1. 각 층이 단순한 곱셈과 덧셈(선형 변환)만 수행한다면?
			2. 층을 백 개, 천 개 쌓아도 결국 수학적으로는 '거대한 하나의 선형식'으로 압축됨
			- 결론 : 아무리 층이 깊어도, 피자는 여전히 한 번밖에 자를 수 없음. 비선형적인 변화가 절실함
	- #### 돌파구 2 : 비선형성의 마법, 활성화 함수
		- 활성화 함수
			- 선형 변환 사이사이에 들어가 평탄한 공간을 구부리고 꺾어, 복잡한 결정 경계(Decision Boundary)를 만들 수 있게 해주는 필수 장치
			- 은닉층(구조)과 활성화 함수(비선형성)가 결합될 때, 신경망은 세상의 어떤 복잡한 패턴이라도 표현할 수 있는 능력을 얻게 됨
		- 활성화 함수의 진화
			- Step Function(계단 함수)
				- \[X] 퇴출
				- 너무 극단적이며, 미분이 불가능해 향후 신경망을 '학습'시킬 수 없음
			- Sigmoid(S자 곡선)
				- \[!] 제한적 사용
				- 확률(0~1) 표현에 좋지만, 층이 깊어지면 신호가 약해지는 '기울기 소실' 문제 발생
			- ReLU(꺾은선)
				- \[O] 현대의 표준
				- 연산이 압도적으로 빠르며, 깊은 신경망에서도 신호가 사라지지 않고 잘 전달됨
		- 현대 인공지능의 문지기 : ReLU
			- y = max(0, z)
			- 음수는 무시한다(출력 0)
				- 중요하지 않은 신호는 과감히 차단
			- 양수는 그대로 통과시킨다
				- 중요한 신호는 변형 없이 그대로 전달
			- 이 단순한 한 번의 꺾임이 수천 개의 뉴런과 결합하면, 놀라울 정도로 복잡하고 정교한 결정 경계를 그려냄
- ### 완성된 인공 뇌의 설계도 : 다층 퍼셉트론 (MLP)
	- #### 입력층(Input Layer)
		- 세상의 데이터를 받아들이는 감각 기관
	- #### 은닉층(Hidden Layers)
		- 데이터를 새로운 관점으로 해석하는 사고 기관
		- (가중합 + 활성화 함수의 반복)
	- #### 출력층(Output Layer)
		- 최종 예측값을 내놓는 결단 기관
- ### 순전파 연산(Forward Propagation)
	- #### 예측값을 도출하는 기계적인 여정
	- step 1 : 가중합
	- step 2 : 활성화
	- step 3 : 다음 층으로 전달
		- 은닉층의 결과가 다음 층의 새로운 입력이 됨
	- step 4 : 최종 출력
		- 예측값 y^ 산출
	- 순전파란, 주어진 데이터를 설계된 층(Layer)의 순서대로 통과시켜 최종 결과를 만들어내는 일련의 계산 과정임
- ### 연산의 스케일업 : 왜 행렬인가?
	- 뉴런 단위 개별 계산 : 비효율적 수작업
	- 행렬 곱 : 대규모 병렬 처리
	- 여러 뉴런의 계산을 행렬 W 하나로 묶으면 한 번에 연산이 가능함
	- 이것이 행렬 연산에 특화된 GPU가 현대 AI의 심장이 된 이유임
- ### 신경망 코딩의 최대 암초 : 차원 매칭 퍼즐
	- 행렬 곱의 물리적 결합 메커니즘
	- 절대 규칙
		- (N x M) x (M x K) = (N x K)
		- 안쪽 차원(M)이 반드시 물리적으로 일치해야만 안쪽 차원(M)이 반드시 물리적으로 일치해야만 연산 블록이 결합됨

## 실습
- XOR 한계부터 순전파와 행렬 shape까지
- ### 퍼셉트론은 가중합으로 판단 기준을 만듦
	- z = w1x1 + w2x2 + b
	- z >= 0이면 1, 그렇지 않으면 0
	- 가중치 w는 각 입력의 영향력을 나타냄
	- 편향 b는 판단 기준의 위치를 이동시킴
	- X @ w는 여러 관측치의 가중합을 한 번에 계산함
	- ```python
	  def step(z):
		  return (z >= 0).astype(int)
		  
	  def perceptron_forward(X, w, b):
		  z = X @ w + b
		  return z, step(z)
	  ```
	  - #### 단일 퍼셉트론은 XOR에서 오분류를 남긴다
		  - AND Accuracy : 1.00
		  - XOR Accuracy : 0.50
		  - 학습 횟수의 문제가 아님
			  - 모델이 만들 수 있는 경계가 직선 하나이기 때문임
- ### 선형층을 여러번 연결해도 결과는 다시 선형이다
	- (XW1)W2 = X(W1W2) - 행렬곱의 결합법칙
	- 층 사이에 비선형 변환이 없으면 깊이를 늘려도 표현력이 늘지 않는다
	- #### 활성화 함수가 선형성의 사슬을 끊는다
		- Step : 판단은 직관적이지만 기울기 학습에 불편
		- Sigmoid : 0과 1사이로 변환
			- 큰 |z|에서 기울기 감소
		- ReLU : 음수는 0, 양수는 통과
			- 은닉층에서 널리 사용
	- #### 은닉층과 ReLU를 추가한 MLP
		- ```python
		  mlp = MLPClassifier(
			  hidden_layer_sizes=(4,),
			  activation="relu",
			  solver='lbfgs',
			  max_iter=5000,
			  random_state=0
		  )
		  mlp.fit(X, y_xor)
		  ```
		- hidden_layer_sizes=(4,)
			- 뉴런 4개인 은닉층 한 개
		- activation='relu'
			- 은닉층에 비선형 변환 추가
	- #### MLP는 XOR의 비선형 결정 경계를 표현한다
		- [[4. 퍼셉트론에서_MLP까지.pdf#9]]
		- 그림에서 볼 점
			- 경계가 직선 하나가 아니다
			- 네 점을 모두 올바르게 분류한다
			- 은닉 뉴런의 변환을 출력층이 조합한다
		- 복잡한 경계가 항상 좋은 것은 아니다
- ### 순전파는 층별 가중합과 활성화의 반복이다
	- 1) 가중합
		- Z1 = XW1 + b1
	- 2) 활성화
		- A1 = ReLU(Z1)
	- 3) 다음 층 가중합
		- Z2 = A1W2 + b2
	- 4) 최종 확률
		- y^ = sigmoid(Z2)
	- 샘플 수는 유지되고 열 수는 각 층의 뉴런 수에 따라 바뀐다
	- #### 행렬 shape은 뉴런 연결 구조를 보여준다
		- (4 x 2) @ (2 x 2) = (4 x 2)
			- 안쪽 차원이 같아야 곱할 수 있다
		- (4 x 2) @ (2 x 1) = (4 x 1)
			- 4는 샘플 수, 마지막 1은 출력 뉴런 수
		- shape 확인은 가장 빠른 신경망 디버깅 방법 중 하나다

- ### 실습에서 확인한 핵심
	- 단일 퍼셉트론 : 직선 결정 경계만 표현
	- XOR : 선형 분리 불가능
	- 은닉층과 ReLU : 비선형 결정 경계 표현
	- 순전파 : 행렬곱과 활성화의 반복
- ### 실습 과제
	- 은닉층의 뉴런 수에 따른 XOR 학습 결과 비교
		- 은닉층 뉴런의 수가 1개부터 4개까지일 때의 예측값과 정확도를 구하여 비교
		- 은닉 뉴런의 수가 증가하면서 XOR 예측 결과가 달라진 이유 설명
		- 은닉 뉴런 수가 많을 수록 모든 분류 문제에서 늘 좋은 성능을 낸다고 볼 수 있는가?
