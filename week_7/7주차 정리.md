
## 깊은 신경망, 어떻게 잘 배우게 할까? 
### 기울기 소실
- 문제 : 앞쪽 층까지 학습 신호가 닿지 않는다
- 해결 : ReLU, 가중치 초기화
- #### 범인 : 시그모이드의 기울기는 최대 0.25
	- σ'(z) = σ(z) \* \[1 - σ(z)]
	- 왜 0.25?
		- σ(z)는 0과 1 사이. 두 수 a와 (1-a)의 곱은 a = 0.5일 때 가장 크다
		- 0.5 x 0.5 = 0.25
	- 포화 구간
		- 출력이 0이나 1에 붙으면 기울기는 거의 0. 뉴런이 '확신'할수록 배우지 못한다
- #### 0.25를 층마다 곱하면?
	- 10층이면 앞쪽 층의 기울기는 약 100만 분의 1- 최댓값으로 계산해도 이렇다
	- 주의 : 실제 기울기에는 가중치의 크기와 여러 경로의 합도 곱해짐.
		- 그래서 다음 해볍은 활성화 함수와 가중치 초기화 두갈래임
- #### ReLU : 양수 구간에서는 신호를 깎지 않는다
	- ReLU(z) = max(0, z)
	- 장점 : 기울기 1을 그대로 통과
		- 시그모이드 최대 0.25 vs ReLU
		- 1층을 쌓아도 활성화 함수 때문에 줄지 않음
		- 계산도 매우 빠름
	- 주의 : 죽은 ReLU
		- 입력이 계속 음수면 기울기가 0 -> 그 뉴런은 영영 멈출 수 있다
		- 보완 : Leaky ReLU (음수 쪽에 작은 기울기)
- #### 가중치 초기화 : 출발점이 신호의 운명을 정한다
	- 목표 : 층을 지나도 신호의 분산이 크게 변하지 않게
	- Xavier 초기화
		- 시그모이드, tanh 계열
		- Var(w) = 2 / (n_in + n_out)
	- He 초기화
		- Var(w) = 2 / n_in
### 최적화
- 문제 : 손실이 흔들리거나 너무 느리게 준다
- 해결 : 모멘텀, RMSprop, Adam
- #### SGD : 안개 낀 산에서 발밑만 보고 내려가기
	- Wt+1 = Wt - n \* gt
	- 손실 = 산의 높이, 가중치 = 지금 위치
	- 기울기 g = 발밑의 경사, 학습률 n = 보폭
	- 미니배치 = 매번 일부 자료만 보고 경사를 짐작
	- 그래서 방향이 매번 조금씩 흔들림
- #### SGD가 고전하는 두 가지 지형
	- 좁고 긴 골짜기
		- 가파른 벽 쪽으로 왔다 갔다, 정작 골짜기 방향으로는 조금씩만 전진
	- 평지, 안장점
		- 경사가 거의 0 -> 보폭이 거의 0
		- 최저점이 아닌데도 멈춘 듯 느려짐
- #### 모멘텀 : 굴러가는 공처럼 관성을 더한다
	- 같은 방향이 이어지면 -> 가속
		- 완만한 골짜기 방향으로 점점 빨라진다
	- 방향이 번갈아 바뀌면 -> 상쇄
		- 지그재그 성분은 서로 지워져 흔들림이 준다
- #### Adagrad, RMSprop : 변수마다 보폭을 다르게
	- 많이 움직인 변수는 보폭을 줄이고, 거의 안 움직인 변수는 보폭을 키움 w <- w - n \* g / (root)s
	- Adagrad : 전부 기억하는 일기장
		- 과거 기울기 제곱을 계속 더함 -> s는 커지기만 -> 보폭이 0에 가까워져 학습이 멈출 수 있음
	- RMSprop : 최근 메모장
		- 최근 기울기 제곱의 이동평균 -> 오래된 기억은 희미해짐 -> 보폭이 계속 살아 있다
- #### Adam = 모멘텀(방향) + RMSprop(보폭)
	- 방향 기억(모멘텀)
		- 기울기의 평균적 방향
	- 크기 기억 (RMSprop)
		- 기울기 크기의 평균적 규모
	- 가장 많이 쓰는 좋은 출발점, 하지만 모든 문제에서 최고는 아님
### 규제화
- 문제 : 훈련 자료만 외우고 새 자료는 못 푼다
- 해결 : L1, L2, 드롭아웃, 조기 종료
- #### 과적합 : 기출문제 답만 외운 학생
	- 점선 왼쪽 : 함께 배우는 중
		- 두 손실이 같이 내려간다 = 일반적인 규칙을 배우고 있다
	- 점선 오른쪽 : 외우기 시작
		- 훈련 손실↓, 검증 손실↑ = 훈련 자료의 우연한 패턴까지 맞추는 중
	- 그래서 자료를 훈련, 검증으로 나누고, 검증 손실을 계속 지켜본다
- #### L1, L2 규제 : 큰 가중치에 벌점을 매긴다
	- 전체 목표 = 원래 손실 + λ · 규제 항
		- λ가 클수록 단순한 모델 쪽으로 강하게 끌어당긴다
	- L1 규제 
		- 덜 중요한 가중치를 정확히 0으로 -> 필요 없는 특징을 지움
	- L2 규제
		- 모든 가중치를 고르게 작게 -> 한 특징에 과하게 기대지 않음
- #### 드롭아웃 : 훈련 때마다 일부 뉴런을 쉬게 한다
	- 훈련 중
		- 매 단계 무작위로 일부 뉴런의 출력을 0으로
		- 매번 다른 '작은 신경망'이 학습됨
	- 테스트, 실제 사용
		- 모든 뉴런을 켠다
		- 여러 작은 신경망의 의견을 모은 효과
	- 팀 프로젝트 비유 : 아무나 결석할 수 있으면, 모두가 전체 내용을 이해하게 된다
- #### 조기 종료 : 나빠지기 시작하면 멈춘다
	- patience(인내심)
		- 한두 번 흔들려도 바로 멈추지 않고 몇 번 더 기다린다
	- 최고 가중치 복원
		- 마지막이 아니라 가장 좋았던 에폭의 가중치를 쓴다
